# Kanting

A Video RAG (Retrieval Augmented Generation) system that enables intelligent video content search and retrieval. Upload videos, automatically extract and index transcripts, then query your video library using natural language to get relevant clips and AI-generated answers.

## Features

- **Video Ingestion**: Download videos from URLs and automatically extract transcripts using OpenAI Whisper
- **Semantic Search**: Store transcripts in a vector database for efficient similarity search
- **Intelligent Query**: Ask natural language questions and receive relevant video segments
- **AI-Powered Answers**: Get context-aware responses generated by Claude using retrieved video content
- **Automatic Note Generation**: Generate structured notes with key points, summaries, and takeaways from video content
- **Timestamped Results**: Receive direct links to relevant video moments

## Tech Stack

- **Backend**: Flask with CORS support
- **Speech-to-Text**: OpenAI Whisper (medium model)
- **Embeddings**: Sentence Transformers
- **Vector Store**: Custom implementation using NumPy and scikit-learn
- **LLM Integration**: Anthropic Claude for answer generation
- **Video Processing**: yt-dlp for downloads, ffmpeg for clip extraction

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/kanting.git
cd kanting
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Set up environment variables:
```bash
export ANTHROPIC_API_KEY=your_api_key_here
```

## Running Locally

Start the Flask development server:

```bash
python api/index.py
```

The API will be available at `http://localhost:5000`.

## API Endpoints

### Store Video Transcript
```http
POST /store-transcript
Content-Type: application/json

{
  "video_url": "https://youtube.com/watch?v=..."
}
```

Downloads the video, extracts the transcript using Whisper, stores it in the vector database, and generates structured notes.

**Response:**
```json
{
  "video_id": "unique_id",
  "status": "success",
  "notes": "Generated notes with main topic, summary, key points..."
}
```

### Query Videos
```http
POST /query
Content-Type: application/json

{
  "query": "What did they say about machine learning?"
}
```

Searches the vector store for relevant segments and returns an AI-generated answer with video timestamps.

**Response:**
```json
{
  "answer": "AI-generated response based on video content",
  "video_url": "https://youtube.com/watch?v=...&t=120",
  "clip_start": 120.5,
  "clip_end": 145.2,
  "video_id": "unique_id",
  "segments_used": 3,
  "max_similarity": 0.85
}
```

### Get Statistics
```http
GET /stats
```

Returns storage statistics including number of videos and segments indexed.

### Health Check
```http
GET /health
```

Returns system health status.

## How It Works

1. **Video Ingestion**: When a video URL is submitted, the system downloads the video and uses Whisper to generate a timestamped transcript.

2. **Indexing**: The transcript is chunked into segments and encoded into embeddings using Sentence Transformers. These embeddings are stored in the vector database along with timestamp metadata.

3. **Query Processing**: User queries are encoded into the same embedding space and compared against stored segments using cosine similarity.

4. **Answer Generation**: The most relevant segments are retrieved and passed to Claude, which generates a natural language answer grounded in the video content.

5. **Clip Retrieval**: The system calculates optimal clip boundaries from the retrieved segments and returns a timestamped URL pointing to the relevant portion of the original video.
